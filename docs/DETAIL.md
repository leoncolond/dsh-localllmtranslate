# 翻译（dsh-localllmtranslate）

左侧栏「翻译」入口对应的本地翻译工作台。翻译由本机 llama.cpp 上运行的 **Hy-MT2-1.8B** 完成，输入文本不会发送到任何云端服务。

## 能做什么

- **双栏实时翻译**：默认左右分栏（左侧原文、右侧译文），可在「设置 → 界面 → 布局方向」切换为上下分栏（上方译文、下方原文）；停止输入约 0.8 秒后自动翻译，逐段流式出译文。
- **可收起的内侧栏**：面板内的翻译 / 术语本 / 历史导航默认在**右侧**，可在「设置 → 界面 → 侧栏位置」改回左侧；侧栏内缘的圆形按钮可收起，收起后边缘保留展开按钮，图标方向随左/右位置镜像。
- **提示播报器**：所有临时提示集中到右下角，用 CLI 打字 / 退格风格显示；点击某条提示会固定它，不会自动刷走，可点 × 关闭。设置里可整体关闭提示播报。
- **设置页分类**：模型 / 界面 / 诊断三个分类；左上角可返回上一个页面，右上角可恢复默认设置。
- **模型卡片手势**：双击左侧的模型状态卡片可加载或停止模型（可在设置里关闭；关闭后点击不做任何反应）。
- **实时开关**：关闭「实时翻译」后改为点「翻译」手动翻译；手动翻译会保存历史并按设置抽取术语。
- **段落级双向高亮**：右侧译文按段落与原文一一对应；悬停任一段会在译文栏下方浮出对应原文片段（毛玻璃浮层，不挤动译文行）。左侧切到「对照」后，悬停原文段落会同时高亮对应译文；在编辑模式下选中文字也会高亮对应译文段。点击任一段可固定浮层，再点一次取消。
- **38 种语言**：默认自动检测原文；中文原文默认译成英文，其他语言默认译成中文。也可以手动指定源语言和目标语言，中间按钮可一键互换。
- **自动检测按占比**：先统计各文字系统的字符占比再选语言；中英混排的长文不会因为夹一句中文就整篇判成中文，代码块 / 行内代码 / URL / Windows 路径不参与统计。
- **术语本**：手动增删改、搜索、CSV / JSON 导入导出；术语可限定为「全局」或「当前语言对」。
- **自动术语候选**：手动翻译完成后，本地模型从原文 / 译文中抽取术语对，进入「待确认」列表；采纳后才参与后续翻译。实时翻译不自动抽取，可用译文栏的「抽取术语」按钮手动触发。候选词默认批量翻译（一次请求翻完），模型没有按行返回时自动回退为逐词请求。
- **翻译提示词**：命中术语时按 Hy-MT2 官方术语模板注入（`参考下面的翻译：A 翻译成 B …`），未命中则使用默认翻译指令。
- **历史记录**：面板左侧「历史」二级菜单列出最近翻译；可搜索、载入、单条删除或清空。默认保留 200 条。实时翻译不会自动写入历史，可用译文栏的「保存历史」按钮保存当前结果。
- **文件与导出**：导入 `.txt` / `.md` / `.srt`；导出纯译文、双语对照或双语字幕（`.srt`，保留原时间轴）。
- **Agent 工具**：向对话暴露 `translate_text`，模型可以直接调用本地翻译能力。

## 首次使用

1. 打开左侧栏 **翻译**。
2. 首次进入若未找到模型，会按「设置 → 界面 → 自动下载默认模型」的开关自动拉取 **Hy-MT2-1.8B F16 GGUF**（约 3.3 GiB），保存在 `$DSH_HOME/localllmtranslate/models/`；也可以关闭自动下载，在「设置 → 模型」里手动下载。
3. 下载完成后若「下载完成后自动启动模型」开启，会直接启动；否则在设置里点「启动模型」。插件会自动寻找本机 `llama-server`（PATH、WinGet 安装目录、`$DSH_HOME/local-model/runtime` 以及设置里填写的路径）。
4. 在左侧原文输入或粘贴文本，右侧会自动出现译文；布局方向、侧栏位置等都在「设置 → 界面」里。

如果本机没有 llama.cpp，「设置 → 模型」顶部会出现**首次配置向导**：

1. 安装运行时：Windows 一键 winget / macOS 一键 Homebrew；其他平台复制命令或打开 Releases，安装后点「重新检测」。
2. 下载默认模型（也可以提前关闭自动下载，手动准备）。
3. 启动模型，成功后点「开始翻译」。

安装过程中可以查看日志；运行时安装完成后会自动重新扫描，并触发「下载后自动启动」。

## 模型与运行时

- 默认模型：`Hy-MT2-1.8B.f16.gguf`（社区转换的 F16 权重，可在标准 llama.cpp 上运行）。
- 该 F16 GGUF 的 tokenizer 元数据缺少正确的 EOS 标记，插件启动时会自动追加
  `--override-kv tokenizer.ggml.eos_token_id=int:120020`，否则模型会在译文后继续编造内容。可在设置里关闭。
- 启动参数默认：`-c 8192 -ngl 99 --jinja --no-warmup -np 1`，端口 `18081`。
- 连续 10 分钟没有翻译请求会卸载模型并释放显存；下一次翻译自动重新加载。
- 官方 `tencent/Hy-MT2-1.8B-GGUF` 只有 Q4_K_M / Q6_K / Q8_0，没有 F16；本插件默认使用 F16 社区转换版。

## 已知边界

- 对齐粒度是**段落级**，不是词级；超长段落会先按句切分再合并，段落一一对应仍然成立。
- 1.8B 模型适合通用文本；专业领域建议先在术语本里固定关键译法。
- 自动术语抽取是「候选」机制，不保证每条都正确，需人工采纳。
- 插件只监听本机回环地址；通过局域网 / 远程 Web UI 打开时，模型下载、启动与翻译请求会被 Harness 的信任检查拒绝。
- 翻译历史与术语本保存在 `$DSH_HOME/localllmtranslate/state/`（`history.json`、`glossary.json`、`settings.json`），是本机明文文件。
- `history.json` 以 8 MiB 为上限（保留最新记录）；单条超大记录仍会保留，避免丢失刚保存的长文。
- 模型推理为单并发；连续大量段落会串行执行，界面会显示进度。
- 实时翻译只在停止输入约 0.8 秒后触发，输入过程中不会反复请求；长文仍要逐段等待。
- 实时翻译默认不写历史、不自动抽取术语；用「翻译」按钮可连同历史与候选术语一起处理，或用译文栏的「保存历史」「抽取术语」单独执行。
- 「恢复默认设置」会保留模型文件路径，但重置端口、上下文、下载地址与界面选项；正在运行的模型可能因此卸载一次。
- 关闭「提示播报」后不再出现右下角临时提示；翻译失败等阻塞错误仍显示在页面错误条中。
